# Job queue

Contents of `packages/jobqueue`: the job queue for school makerspaces (steps and rules: `docs/progress/queue.md`). Its own package and switch so it could be split out later; no workspace imports it yet. Keep this list current when you add or change a file here.

- `queue.ts` (Q1): the queue's rules as plain functions on plain data, no page, no network, no clock. `newQueue(machines)`, `withStudent(queue, id, displayName)` (the only personal data: a name the teacher types); `apply(queue, action)` for every move (send, check, approve, return, withdraw, move, start, finish, requeue), never throws, never changes the queue given, and refuses with a kind (`bad-input`, `not-found`, `not-allowed`, `wrong-state`, `machine-busy`) and a detail; `placeOf` (place, jobs and known minutes ahead, unknown ones counted apart); `studentView` (a student's own jobs and the queue lengths only, never another student's name or file); `totals` per machine and per student over every finished run (a failed run put back in the queue still counts), recorded use else the estimate, with how many came from estimates or are unknown; `QUEUE_LIMITS`, `refusalWords`, `STATE_WORDS`. `test/queue.test.ts`: hand-worked sessions, every refusal, 0.9×/1.1× of every limit, privacy of the student's view, 200 seeded sessions against a table model.
