# UI kit

Contents of `packages/ui`; the rules are in packages/CLAUDE.md and the root CLAUDE.md. Keep this list current when you add or change a file here.

- shared UI kit: number formatting, theme (`theme.css`: the base layout, including split view, and on `:root` the clean look's shared values `--look-*`, UX2: corners, shadows, the card colour, the bright blue glow and fill, target sizes, spacing; checked by `test/look.test.ts`; U1a: every colour is a named token in the second `:root` block of theme.css (dark values; the light theme overrides them), no raw colour in any other CSS file, checked by `test/tokens.test.ts`; U1b: `:root[data-theme="light"]` overrides them (`test/light.test.ts`), `theme-choice.ts` is the Settings choice and `data-theme` on the root (`public/theme-init.js` in apps/fission sets it before the first paint; `test/theme-choice.test.ts`), and an element marked `data-scene="dark"` keeps the dark values; each feature's own styles are `src/styles/<feature>.css`, every selector starting with `.<feature>`, loaded by the app without a list), the workspace button (`switcher.ts`, U0f2b: DESIGN ▾ naming the page on screen, its menu the ten workspaces, the one on screen marked, the ones not built yet greyed with Coming soon; `styles/workspace-menu.css`; `test/switcher.test.ts`), split choices (`split.ts`), the warm-workspace pool (`warm.ts`, X7: one mounted instance per workspace, living in one pane, asleep unless shown), the link badge, the downstream chip (`downstream-chip.ts`), the file-drop outline (`styles/file-drop.css`, X6a) and the change note (`change-note.ts`; the strip of notes the shell shows over each pane is styled in `styles/notes-strip.css`), the Settings page (`settings.ts`: six card sections, the browser-only `SettingsStore`; `styles/settings.css`, `styles/settings-button.css` for the top bar gear; browser check `apps/fission/e2e/settings.mjs`), the keyboard shortcuts list (`shortcut-list.ts`, `styles/shortcut-list.css`, X7b), the top bar's Undo and Redo (`styles/undo-redo.css`, step 20b), the History button and panel beside them (`history-panel.ts`, `styles/history-panel.css`: the recent steps newest first, a press jumps the project back or forward to that step, a bottom sheet at phone width; `test/history-panel.test.ts`, browser check `apps/fission/e2e/history.mjs`), the AI assistant panel's styles (`styles/assistant.css`, AI2), the guide's styles (`styles/guide.css`; the guide itself is in packages/viewport `src/guide/`), placeholder page.
- `styles/split-view.css`: split view's one-row toolbars, the pane's choice in the toolbar row, the placeholder card; `defaultSplit` picks the first working workspace.
- `styles/dark-select.css`: every drop-down list's open list dark and readable (`class="dark-select"` on each select: `color-scheme: dark` and solid dark options, since Windows Chrome painted the list white under light words); browser check `apps/fission/e2e/select-lists.mjs`.
- `save-file.ts`: saving as a desktop app does (`saveFile`: the browser's save picker where there is one, else `askName`'s small box and a download; a returned handle is written again without asking; `fileNameFor` makes names safe; `PROJECT_KIND` .spindle, `STL_KIND`, `PNG_KIND` for File > Save picture); a page driven by a test downloads under the suggested name; `test/save-file.test.ts`, `e2e/save-name.mjs`, `styles/save-name.css`.
- `press-guard.ts`: `repeatGuard`, one per button that saves a file: a press within `REPEAT_MS` (500 ms) of the one before is the same burst (a double-click, a held Enter, a mashed button), so one file; `reset` after a change lets the next press through; `test/press-guard.test.ts`, `e2e/double-press.mjs`.
- `keep-typing-visible.ts`: `keepTypingVisible(window)`, started once by the shell: when the window or the visual viewport changes size (the phone's keyboard opening), the focused box that takes typing (`takesTyping`) and no longer shows whole (`typingHidden`, pure) is scrolled to the middle of what shows; `test/keep-typing-visible.test.ts`, `apps/fission/e2e/phone-leftovers.mjs`. `styles/tiny-window.css`: absurdly small windows (260 px wide or less: the top bar wraps instead of spilling sideways; 300 px tall or less: the workspace keeps 300 px and the page scrolls up and down), the `tiny-window` class on <body>.
- `command-search.ts`: the S key's command search box (`commandSearch`: every command the workspace gives, by name with its key, typing narrows, arrows and Enter run one, Escape or a press outside closes; an off command stays listed, dimmed, with its reason, and never runs; `matchCommands` is the pure matcher); `test/command-search.test.ts`, `e2e/shortcuts.mjs`, `styles/command-search.css`.
- `file-menu.ts` (U0f2a): the app bar's File ▾ (`fileMenu`, `fileSections`): New, Open…, Save, Save As…, then the exports (on a phone, `fileSections(parts, true)` at `PHONE_SHEET_QUERY`, the exports first, above the 34% sheet's fold, SL #648); Open, Save and Save As the shell's, New and the exports the workspace's on screen (core's `FileEntries`), read each time it opens, off with why where there is nothing to do; `test/file-menu.test.ts`. `styles/app-bar.css`: the bar's ends (File ▾, the Save, Undo and Redo icons; AI, Guide and Community small at the right; Save in File ▾ and File ▾ filling the row at phone width).
- `open-elsewhere.ts`: the shell's question before a file opened, dropped or pasted takes you to a workspace not on screen ("Open in Image?", `openElsewhere`, `openElsewhereWords`; Cancel, Escape or a click outside open nothing); `test/open-elsewhere.test.ts`, browser checks in apps/fission `e2e/files.mjs`. `styles/open-elsewhere.css`.
- `project-list.ts` (U6a; round 2 hunt A2, A3): File ▾ > Projects in this browser… (`projectList`, `projectRows`, `savedWhen`): every kept project, newest first, when it was saved, the open one marked and offering no Open or Delete; Delete asks in the row first (Keep it has the focus); a refused Open, Delete or list says why in the dialog; the shell does the opening and deleting (apps/fission `src/projects.ts`, `openStored` in main.ts). `test/project-list.test.ts`, browser checks in apps/fission `e2e/projects.mjs`. `styles/project-list.css` (a full-screen sheet at phone width).
- `home-screen.ts` (U6b): the home screen (`homeScreen`, pure `homeRows`, `filterRows`, `workspacesIn`, `carryOnRow`): a full-window layer over the open project with the Carry on card (last used readable project), New project, Open file…, Upload STL…, search by name, a workspace filter, the kept projects most recently used first with Open, Rename and Delete (asks first; the open project gets neither Rename nor Delete), and the guide link. Escape or Back returns to the project; keys stay inside. Built only when the shell's `__HOME_SCREEN__` switch is on (apps/fission `home.config.mjs`, off until released). `test/home-screen.test.ts` (hand-worked search, filter and card; the screen in happy-dom), browser check apps/fission `e2e/home.mjs` (`npm run e2e:home`). `styles/home-screen.css`. File ▾ gets a Home… entry (`parts.home`) when the screen is built.
- `version-list.ts` (missing basics 3b): File ▾ > Earlier versions… (`versionList`, `versionRows`, `versionTime`): the open project's kept versions, newest first, when each was saved; Restore hands the shell the version's time (apps/fission `restoreVersion`, one undo step) and closes, a refusal is said in the dialog; wears `styles/project-list.css`. `test/version-list.test.ts`, browser checks in apps/fission `e2e/versions.mjs`. Signed in with the project in the account (account features 2), `list` also gives the account's versions (`AccountVersions`): `versionRows` merges them by exact save time, an account-only row carries `data-where="account"` and the From your account tag (`styles/version-list.css`), and `restore(at, where)` says where to read it.
- `my-designs.ts` (account features 1): File ▾ > My designs… (`myDesigns`, `designRows`, `sizeWords`, `spaceWords`, `othersWords`, `tagOf`): the designs in the person's account, newest first, each with its picture, name, workspace tag and when it was saved; Open (the shell brings it in and opens it) and Delete (asks in the row first; the browser's copy stays); the space used; the Keep my designs in my account switch (put back when refused); the question about projects from before signing in (Keep them / Not now, then Keep them too). `styles/my-designs.css`, `test/my-designs.test.ts`, browser checks in apps/fission `e2e/my-designs.mjs`.
- `menu-button.ts` (U0d): a button that drops down a menu of sections and items (keys, off items saying why, ArrowUp/Down, Home/End, Escape back to the button, a press outside closes; placed under the button by `menuPlace`, kept on the screen). - `project-name.ts` (UI audit 2026-11-12, Ben's choice A): the open project's name in the top bar's empty middle, renamed in place (`projectNameBox`: Enter or leaving commits, Escape puts it back, an empty or unchanged name changes nothing, `refresh` never overwrites typing; `nameToKeep` trims and cuts to the limit). - `styles/design-tabs-bar.css` (tabs T3a): the design tabs' part of the top bar, the phone's count button (design-tabs.ts `count`) and the room the narrowest phones make for it; `design-tabs.css` is the strip and its list.

- `icons.ts` (U0f, from U3a): the app's own flat two-tone icons on a 24 grid (lines in `currentColor`, the second tone the same colour at 0.35), `iconSvg(doc, name, size)` for the toolbars, menus and browser rows. `test/icons.test.ts` reads every path back (absolute M L H V A C S Z only) and checks it stays 2 in from the edge; the sheet at 16, 20, 24 and 48 px in both themes is `/mnt/project-files/compact-ui/u0f/icon-sheet.png`. `withIcon(el, name, size)` puts an icon before an element's words, kept in a `.tool-word` span (its accessible name).
- `tool-group.ts` (U0f1): one group of the Fusion-style toolbar, `toolGroup(doc, { name, menu?, solo? })`: a row of icon buttons (`add`, 24 px, `TOOL_ICON_SIZE`; words hidden from sight, kept as the name) over the group's name, which is its menu's button ("CREATE ▾") when it has one; a solo group (Insert ▾) is one button, its icon over its name. - `styles/phone-short.css` (U5a): a phone held sideways (500 px tall or less: the toolbar one 45 px row) and a window 641–760 px wide (AI, Guide and Community icons only); class `phone-short` on `<body>`, every rule inside a media query; tested in `apps/fission/e2e/phone-short.mjs`.

- `skeleton.ts` (loading skeletons, 10-29): shimmering placeholder shapes while something loads (`skeleton(doc, "app" | "view" | "lines")`, `holdSkeleton(host, shape)` until `done()`, `adoptSkeleton` for one already in the page, `whileLoading`); invisible for the first `SKELETON_DELAY_MS` (200), faded out over `SKELETON_FADE_MS` (160) once seen (`leaveAfter`), still under reduced motion. - `src/design-defaults.ts`: the Design defaults (U2b): `startDesignDefaults` wears the stored grid size (mm) and Snap to grid as `data-grid-size` and `data-grid-snap` on the root; `currentDesignDefaults(doc)` is what a new sketch reads (Design `workspace.ts` `startNewSketch`); Settings > Design is `settings.ts` `gridRows` (the box in the chosen unit, refusals from @fission/core `lengthLimitRefusal`, `styles/settings-grid.css`); the AI row there opens the assistant's provider settings, which stay in the assistant panel (`apps/fission/src/assistant.ts`). `test/design-defaults.test.ts`, `workspaces/design/test/design-defaults.test.ts`, `apps/fission/e2e/design-defaults.mjs`.
