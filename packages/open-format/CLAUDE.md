# Open format

Contents of `packages/open-format` (`@fission/open-format`): the reference reader, writer and validator of the open SpindleLabs package format, draft 0.1 (`docs/open-format/spec.md`). The rules are in packages/CLAUDE.md and the root CLAUDE.md. Keep this list current when you add or change a file here.

A self-contained reference for anyone to read: no npm dependencies (not even `@fission/core`), only web-standard APIs present in Node 22 and browsers (`Uint8Array`, `TextDecoder` with `fatal`, `crypto.subtle.digest`, `CompressionStream`/`DecompressionStream('deflate-raw')`). Not used by the app yet (phase 0 of the spec's migration plan).

- `src/errors.ts`: `FormatError` with a stable `code` for every refusal rule (`ERROR_CODES`, one per rule, commented), and the `Warning` codes for optional parts dropped while reading (`WARNING_CODES`). Callers decide by `code`, never by the message.
- `src/crc32.ts`: CRC-32 as zip uses it (table-driven).
- `src/strict-json.ts`: `decodeUtf8Strict` (invalid UTF-8 and a BOM refused) and `parseStrictJson`, a small scanner refusing duplicate keys (after unescaping), nesting over 256 (`MAX_NESTING`), numbers that overflow a double, and anything RFC 8259 refuses; `__proto__` is an ordinary key.
- `src/zip.ts`: `readZipDirectory` (end record, central directory and every local header cross-checked; names, limits, ratio, zip64, encryption, methods, duplicates ignoring case; every byte accounted for, entries back to back from offset 0), `readEntryData` (DEFLATE inflated with a cap at the declared size, CRC-32 checked), `writeZip` (deterministic: given order, DOS time 1980-01-01 00:00, no extra fields, flag bit 11 only for non-ASCII names; DEFLATE falls back to STORE when it saves nothing or would look like a zip bomb), `assembleZip` (lays out raw entries; tests use it to build broken files), `checkEntryName`.
- `src/manifest.ts`: the manifest's types, constants (media types, licences, units `mm`/`deg`/`right-handed, Z up`, limits, role media types) and `validateManifest` (checks in the spec's order: format, minReaderVersion against this reader, major version, then the rest). Unknown fields are allowed and never touched, except inside `units`.
- `src/caches.ts`: structure checks of the caches (`brepProblem`, `meshProblem`, `sourceProblem`, `thumbnailProblem`); each returns what is wrong or null, so a damaged cache is dropped with a warning, never a refusal.
- `src/package.ts`: `identify` ("PK\x03\x04" or plain), `readPackage` (refuses by rule; drops a damaged, stale or mismatched optional part with a warning and removes it from manifest and parts), `writePackage` (sizes and hashes from the bytes, the manifest validated and written with sorted keys, refuses what a reader would refuse), `plainToPackage` (lossless: the history part is the plain file's exact bytes; default id and revision from its SHA-256), `readAny` (either flavour), `canonicalJson`, `sha256Hex`.
- `src/share.ts`: `stripForShare` and `PERSONAL_FIELDS` (the spec's section 16 list).
- `src/cli.ts`: `node --experimental-strip-types packages/open-format/src/cli.ts validate <file>` prints `OK package|plain` (and any warnings) or `<code>: <message>`; `convert <plain.spindle> <out.spindle>`. Reaches the file system through `process.getBuiltinModule`, so it type-checks without Node's types.
- `src/index.ts`: the public exports.

Tests (`npm test` here: `node --experimental-strip-types --no-warnings --test test/*.test.ts`):
- `test/helpers.ts`: `build()` makes a stored package from a manifest edit, a text edit or a raw-entry edit, so each broken file differs from a good one in exactly one way; fixtures (one-face B-rep, one-triangle mesh, PNG); `refuses(p, code)`.
- `test/hand-worked.test.ts`: CRC-32 of "123456789", SHA-256 of "abc", the mimetype entry's bytes at offsets 30 and 38 worked out from the local header layout.
- `test/strict-json.test.ts`, `test/zip.test.ts`, `test/package.test.ts`, `test/caches.test.ts`, `test/share.test.ts`: one broken file per refusal rule, each asserting its code; boundaries (nesting 256/257, display name 3/30 vs 2/31, thumbnail 32 KiB and 0.9×/1.1×, ratio 1000:1 vs 1001:1 and 0.9×/1.1×, names 255/256 bytes, 10,000/10,001 entries, 256 MiB, 1 GiB); round trips (plain to package byte-identical; `writePackage(readPackage(x))` byte-identical; real saved `.spindle` files from the repo).
- `test/random.test.ts`: seeded (mulberry32, seed printed on failure) byte flips, insertions, deletions and truncations of good files: each reads or throws `FormatError`, within 2 s.

Known gaps against the spec, on purpose for now: case-insensitive name comparison uses `toLowerCase()`, not Unicode simple case folding (they differ for a handful of letters such as the long s); an extension or unknown-role part whose SHA-256 mismatches is dropped with a warning rather than kept for re-save (same result on re-save); the reader refuses unaccounted bytes between entries, which the spec does not forbid in so many words.
