# The Simulate workspace (TestLab)

Contents of `workspaces/simulate`; the rules are in packages/CLAUDE.md and the root CLAUDE.md. Its name for people is TestLab; its id stays `simulate` in code and in project files. The steps are in `docs/progress/testlab.md`; the solver and mesher are kernel work (the private kernel repo's `fea/` crate, from T3). Keep this list current when you add or change a file here.

- `src/index.ts`: the plugin. With `?testlab` (flag.ts) it mounts the page; without it, the Simulate placeholder it was. `readData` is `readTestLab`. `solve` still throws "not implemented" until the solver (T3 to T5).
- `src/flag.ts`: the `?testlab` switch (as Laser's `?laser`: kept for the tab, `?testlab=off` clears it), off until Ben releases TestLab.
- `src/study.ts`: TestLab's data (`TestLabData` version 1 in `project.workspaces.simulate`: studies with a body by stable reference, holds and loads on faces by stable reference with the words they were picked by, mesh size; choices only, never results or geometry), `readTestLab` (each rule refused in words, a newer version as `NewerFormatError`), the pure edits (`addStudy`, `chooseBody`, `toggleHeld`, `togglePushed`: a face is held or pushed, never both; `addLoad`, `removeLoad`, `setLoad`: amount above 0 and at most `MAX_AMOUNT`, a pressure only square into its faces), `newtons` (kg × `G`), `loadWords`, `readyProblems`, `studyFaces`.
- `src/faces.ts`: a study looked up on the design now through core's registry (`facesOf("design", …)`, Design's face finder): `studyNow`, and `lostWords`/`studyLost` (a face an edit took away or gave to two faces, said in words on the hold or load that kept it, never dropped or moved to a guess).
- `src/page.ts`: the page (T1): Design's bodies listed through `objectsOf("design")` (the only one set up without asking), the study in the properties (Held here, Pushed here with each load's amount, unit and direction, Add load, Run), faces picked by tapping the body (each tap one named undo step; picking puts a phone's Properties sheet away and ends on sleep), held faces and each load painted as overlays (`studyOverlays`). The study is a dependency-graph node (`studyNode`, expensive) read from every item its body is made from, so a design edit marks it out of date with a change note; the node stays through an unmount so an Undo's remount keeps the mark. Run checks the set-up against the design now and says solving comes later (`NO_SOLVER_YET`). Styles: `src/styles/testlab-page.css`.
- Tests: `test/study.test.ts` (hand-worked kg to N, the reader's every rule broken, 0.9×/1.1× of `MAX_AMOUNT`), `test/page.test.ts` (happy-dom over a stand-in Design), `test/flag.test.ts`. On the real kernel with Design's own lister, face finder and graph sync: packages/testing `journeys/testlab-link.journey.ts`. Browser check: `apps/fission/e2e/testlab-page.mjs` (in `npm run e2e`).
